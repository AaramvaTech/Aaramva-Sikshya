# I18N-1 — Nepali translations for review (Srijan)

Please read the **Nepali** column. Mark anything that reads unnatural or wrong for a Nepali school context — corrections are applied verbatim, then parent + teacher apps are swept using this validated vocabulary.

Numerals stay Arabic (0–9) in v1. Dates render BS with Nepali month names. Interpolation slots like `{{value}}`, `{{name}}`, `{{date}}` must stay intact in the Nepali.
