## Important note — users vs staff profiles

The `users` table (created in Session 1) holds authentication info:
email, password_hash, role, first_name, last_name.

The `staff_profiles` table extends this with HR-specific data:
join date, salary, department, designation, emergency contacts, etc.

Not every user is a staff member with a profile (e.g. STUDENT and PARENT
roles don't have staff profiles). Staff profiles exist for roles:
SCHOOL_OWNER, PRINCIPAL, ACADEMIC_COORDINATOR, ACCOUNTANT, LIBRARIAN, TEACHER.

-- ─── DEPARTMENTS ──────────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS departments (
  id          UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  name        VARCHAR(100) NOT NULL,     -- "Teaching", "Administration", "Accounts"
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at  TIMESTAMPTZ
);

-- ─── DESIGNATIONS ─────────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS designations (
  id             UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  title          VARCHAR(100) NOT NULL,  -- "Senior Teacher", "Class Teacher", "Accountant"
  department_id  UUID        REFERENCES departments(id),
  created_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at     TIMESTAMPTZ
);

-- ─── STAFF PROFILES ───────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS staff_profiles (
  id                  UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id             UUID        NOT NULL UNIQUE REFERENCES users(id),
  employee_id         VARCHAR(30) NOT NULL UNIQUE,   -- "EMP-2081-0001"
  department_id       UUID        REFERENCES departments(id),
  designation_id      UUID        REFERENCES designations(id),
  date_of_birth       DATE,                          -- AD
  gender              VARCHAR(10),
  nationality         VARCHAR(50) DEFAULT 'Nepali',
  phone               VARCHAR(20),
  permanent_address   TEXT,
  temporary_address   TEXT,
  join_date           DATE        NOT NULL,           -- AD
  end_date            DATE,                           -- AD — NULL if still employed
  employment_type     VARCHAR(20) NOT NULL DEFAULT 'PERMANENT',
                                  -- PERMANENT | TEMPORARY | PART_TIME | CONTRACT
  base_salary         NUMERIC(10,2) NOT NULL DEFAULT 0,
  pan_number          VARCHAR(20),                   -- Nepal PAN (tax)
  bank_name           VARCHAR(100),
  bank_account        VARCHAR(30),
  photo_url           TEXT,
  emergency_contact_name  VARCHAR(100),
  emergency_contact_phone VARCHAR(20),
  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at          TIMESTAMPTZ
);

-- ─── STAFF LEAVE TYPES ────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS leave_types (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  name            VARCHAR(50) NOT NULL,    -- "Sick Leave", "Casual Leave", "Maternity Leave"
  days_per_year   SMALLINT    NOT NULL,    -- entitlement per year
  is_paid         BOOLEAN     NOT NULL DEFAULT true,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ
);

-- ─── STAFF LEAVE REQUESTS ─────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS staff_leave_requests (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID        NOT NULL REFERENCES users(id),
  leave_type_id   UUID        NOT NULL REFERENCES leave_types(id),
  from_date       DATE        NOT NULL,    -- AD
  to_date         DATE        NOT NULL,    -- AD
  total_days      SMALLINT    NOT NULL,
  reason          TEXT,
  status          VARCHAR(20) NOT NULL DEFAULT 'PENDING',
                              -- PENDING | APPROVED | REJECTED | CANCELLED
  applied_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  reviewed_by     UUID        REFERENCES users(id),
  reviewed_at     TIMESTAMPTZ,
  reviewer_note   TEXT,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at      TIMESTAMPTZ
);

-- ─── PAYROLL ──────────────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS payroll_months (
  id               UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  month_bs         SMALLINT    NOT NULL,   -- 1–12 BS month
  year_bs          SMALLINT    NOT NULL,   -- BS year e.g. 2081
  academic_year_id UUID        NOT NULL REFERENCES academic_years(id),
  status           VARCHAR(20) NOT NULL DEFAULT 'DRAFT',
                               -- DRAFT | FINALIZED | PAID
  finalized_at     TIMESTAMPTZ,
  created_by       UUID        NOT NULL REFERENCES users(id),
  created_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (month_bs, year_bs)
);

CREATE TABLE IF NOT EXISTS salary_slips (
  id                UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  payroll_month_id  UUID        NOT NULL REFERENCES payroll_months(id),
  user_id           UUID        NOT NULL REFERENCES users(id),
  staff_profile_id  UUID        NOT NULL REFERENCES staff_profiles(id),
  base_salary       NUMERIC(10,2) NOT NULL,
  -- Allowances (positive)
  allowance_total   NUMERIC(10,2) NOT NULL DEFAULT 0,
  allowances        JSONB       NOT NULL DEFAULT '[]',
                    -- [{ name: "Travel", amount: 500 }, ...]
  -- Deductions (negative)
  deduction_total   NUMERIC(10,2) NOT NULL DEFAULT 0,
  deductions        JSONB       NOT NULL DEFAULT '[]',
                    -- [{ name: "PF", amount: 1000 }, { name: "Tax", amount: 200 }]
  -- Leave deductions
  unpaid_leave_days SMALLINT    NOT NULL DEFAULT 0,
  leave_deduction   NUMERIC(10,2) NOT NULL DEFAULT 0,
  -- Net
  gross_salary      NUMERIC(10,2) GENERATED ALWAYS AS
                    (base_salary + allowance_total) STORED,
  net_salary        NUMERIC(10,2) GENERATED ALWAYS AS
                    (base_salary + allowance_total - deduction_total - leave_deduction) STORED,
  payment_date      DATE,                   -- AD — when physically paid
  payment_method    VARCHAR(20),            -- CASH | BANK_TRANSFER | CHEQUE
  notes             TEXT,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (payroll_month_id, user_id)
);

-- ─── STAFF DOCUMENTS ──────────────────────────────────────────────────────────
CREATE TABLE IF NOT EXISTS staff_documents (
  id            UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       UUID        NOT NULL REFERENCES users(id),
  document_type VARCHAR(50) NOT NULL,  -- CITIZENSHIP, PAN_CARD, DEGREE, CONTRACT, etc.
  file_url      TEXT        NOT NULL,
  file_name     VARCHAR(255),
  uploaded_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at    TIMESTAMPTZ
);

## Business logic rules

### 1. Employee ID format
`EMP-{BS_YEAR}-{4-digit sequence}` e.g. `EMP-2081-0023`
Use the same `sequences` table created in Finance module.

### 2. Create staff — single transaction
`POST /hr/staff` must:
1. Hash the password
2. Insert into `users` table
3. Insert into `staff_profiles` table
4. Both in one transaction — if profile insert fails, user is also rolled back

### 3. Leave balance calculation
```
For a given user + leave_type + year:
  entitlement = leave_types.days_per_year
  used = SUM(total_days) WHERE status = 'APPROVED'
         AND from_date >= fiscal year start AND to_date <= fiscal year end
  balance = entitlement - used
```

### 4. Leave overlap check
When applying for leave, check:
```sql
SELECT COUNT(*) FROM staff_leave_requests
WHERE user_id = $1
  AND status IN ('PENDING', 'APPROVED')
  AND deleted_at IS NULL
  AND from_date <= $toDate
  AND to_date >= $fromDate
```
If COUNT > 0 → throw `ConflictException('Leave request overlaps with existing request')`

### 5. Payroll generation
For each active staff member (end_date IS NULL, deleted_at IS NULL):
  1. Get base_salary from staff_profiles
  2. Calculate leave_deduction:
     - Count unpaid leave days in the month (from staff_attendance where status = 'LEAVE' and leave_type is unpaid... or use a simpler approach: unpaidLeaveDays field in override)
     - leave_deduction = (base_salary / 30) * unpaid_leave_days
  3. Insert salary_slip with default allowances/deductions = empty arrays
  4. Skip staff with existing slip for this payroll_month_id (idempotent)

### 6. Finalize payroll — locked
Once a payroll month is FINALIZED:
  - Cannot add new slips
  - Cannot edit existing slips
  - Any attempt → throw `BadRequestException('Payroll is finalized')`

### 7. Soft-delete staff
Sets `staff_profiles.end_date = today` and `staff_profiles.deleted_at = NOW()`.
Also sets `users.is_active = false` — they can no longer log in.
Must be SCHOOL_OWNER only.
